# Project Metadata

## Project Overview

A modern React component library focused on accessibility, type safety, composability, and excellent developer experience. The library is intended for production applications and aims to provide reusable UI primitives rather than opinionated page-level components.

## Goals

- Provide a collection of accessible, production-ready React components.
- Maintain strict TypeScript type safety with no `any` types.
- Use CSS modules and CSS custom properties for all styling.
- Provide a comprehensive Storybook documentation site.
- Include unit and visual regression tests for all components.
- Support dark mode via theme tokens.
- Provide TypeScript definitions for public APIs.

## Non-Goals

- Not a CSS framework.
- Not a page template library.
- Not a design tool.
- Not a low-code platform.
